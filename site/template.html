Local computation. Independent verification.

A proof you can check
for yourself.

Generate a computation proof on your computer. Open it here to check the math against a registered model, without downloading its weights.

What works today: proofs of a small part of a model operation. The prompt, generated answer and complete inference are not proven. This preview uses experimental setup materials.

    What are you checking?

    1. A model is registered

    The registry records commitments to model weights. You rely on the registrar to associate those commitments with the named model.

    2. A prover supplies evidence

    The prover uses private weights to produce a proof of a specified computation. Today that is one small integer calculation inside a matrix operation.

    3. Your browser checks it

    The verifier checks the proof, accepted input ranges and registered commitment. The proof file cannot supply its own trusted keys.

    4. Coverage matters

    Valid evidence for one calculation does not establish the complete answer. Full-token coverage is a research milestone still ahead.

    Registered models

    These fingerprints identify exact model files. Proof coverage is listed separately. They are project registrations, not certificates signed by the model providers.

    Verify the same file offline

    In a checkout with the pinned Groth16 dependencies installed:

    node site/verify-file.cjs my-proof.llamaproof

    This uses the checkout's trusted registry and the same acceptance policy as the browser. It needs no model weights or network connection. Raw pairing verification alone omits application checks.
